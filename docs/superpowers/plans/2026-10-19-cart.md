# Cart Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Shop becomes "Your cart". Cart days are derived automatically: every unbought, in-shop meal from today on. They're frozen when a trolley is sent. Meals are shown bunched by day with gap markers and flags. Meals are added from the Meals tab through a 14-day pop-up that picks the slot.

**Architecture:**
- **`cartadd.js`** (`window.WeekdayFuelCartAdd`), a new pure module, holds the slot, placement, cart-days, flag and gap logic.
- **`Weekday_Fuel.html` changes:**
  - `shopDays()` becomes derived, and is frozen into `settings.shopDays` when a trolley is sent.
  - The Shop and Meals UI is rebuilt on top of it.

Spec: `docs/superpowers/specs/2026-10-19-cart-design.md`.

**Tech Stack:** Vanilla JS (ES5 module, ES2017 HTML), node:test.

## Global Constraints

- **Git:** commit straight to `main`, staging by explicit path. Never stage `.superpowers/`. Never `git stash`, `git clean` or `git reset --hard`.
- **Escaping:** escape every meal-, catalogue- and day-derived string with `esc`.
- **Storage and ids:**
  - Existing localStorage keys keep their shape. `settings.shopDays` and `settings.shopMode` stay in stored data; `shopMode` is no longer read.
  - Meal ids never change.
- **Day meals and catalogue meals:**
  - Day meals are `{id, slot, t, shop?, bought?, ate?}`, with slots `breakfast`, `lunch`, `dinner` and `snack`.
  - `meals.js` meal `slots` contain `"breakfast"`, `"main"` and/or `"snack"`.
- **Version:** bump only in Task 5.
- **Checks:**
  - Tests: `node --test "apps/android/app/src/test/js/*.test.js"`.
  - Parse check: extract the last inline `<script>` to `%TEMP%/wf.js` and run `node --check`.
  - Browser checks: serve with `npx --yes serve -l 8777 apps/android/app/src/main/assets/weekday_fuel` at 400 px width. Stop only the server you started, and clear the test tab's storage afterwards.

- [ ] **Step 2: Run the tests and confirm they fail** ("Cannot find module").

- [ ] **Step 3: Implement `cartadd.js`.** Use the ES5 IIFE pattern of `plans.js`, with UTC date helpers (`parse`, `fmt`, `isWeekend`, `diffDays(a,b)` = whole days from a to b) and `ORDER = ["breakfast","lunch","snack","dinner"]`.
  - **`naturalSlot`:** breakfast if `slots` includes `"breakfast"`; else, if it includes `"main"`, lunch when no lunch exists, dinner when no dinner exists, otherwise lunch; else snack.
  - **`place`:**
    1. Take `slot = naturalSlot(...)`. If it's snack, return `add`.
    2. Find `existing`, the first meal with that slot.
    3. With no existing meal, return `add`. If it's bought (`isBought`) or eaten (`typeof ate === "string"`), return `locked`. Otherwise return `ask`.
  - **`apply`:**
    1. Copy the array.
    2. For replace, remove the first meal in the slot that is neither bought nor eaten. The `isBought` rule here is `typeof m.bought === "string" && m.bought !== ""`, matching `bought.js`, and the module doesn't import it.
    3. Push the new meal.
    4. Stable-sort by `ORDER`, with unknown slots last.
  - **`cartDays`:** filter the date keys to those ≥ today (ISO string compare) where some meal has `m && mealExists(m.id) && !isBought(m) && m.shop !== false`, then sort.
  - **`dayFlags`:** `few = count < 3 && (!isWeekend(date) || isTrackedWeekend(date)) ? count : null`. For `ahead`, with `n = diffDays(today, date)`: null if `n <= 7`; `"In " + n/7 + " weeks"` if `n % 7 === 0`; else `"In " + n + " days"`.
  - **`gapLabel`:** with `n = diffDays(prev, next)`, if `n <= 1` return null. For each date strictly between, if `!isWeekend(d) || isTrackedWeekend(d)`, return `n + " days later"`. Otherwise return null.
