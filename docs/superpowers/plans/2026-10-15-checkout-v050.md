# Checkout in the app (v0.5.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Spec:** [`docs/superpowers/specs/2026-10-15-checkout-design.md`](../specs/2026-10-15-checkout-design.md)

**Goal:** After sending to the Woolworths trolley, **Checkout** opens an in-app Checkout panel that boosts every Everyday Rewards offer, lists the next 7 days of delivery times to book one, shows the order summary, and **Pay on Woolworths** opens the real checkout to place the order there.

**Architecture:** A new injected script `assets/woolworths/checkout.js` (like `prices.js`) makes the site's own requests in the hidden Woolworths WebView: `start({action:"load"})` boosts and reads; `start({action:"book", timeslotId, windowDate})` books a time and re-reads. The Kotlin host runs it like prices (inject, poll `state()`, 60 s watchdog) on page messages `checkoutLoad` / `checkoutBook` and replies `checkoutDone` / `checkoutError`. A pure `checkoutview.js` shapes the result (offer rows, day tabs, money lines, labels), and `Weekday_Fuel.html` draws the Checkout view in the Shop tab.

**Tech Stack:** Plain JS (ES5-style IIFEs with `async` functions, Node `node:test`), one-file HTML app, Kotlin + Android WebView, `org.json`, GitHub Actions CI.

## Global Constraints

- The app never places the order. **Pay on Woolworths** opens `https://www.woolworths.com.au/checkout` in the in-app Woolworths screen.
- Boosts are automatic every time the Checkout panel opens: every offer whose `boostState` is `NOT_BOOSTED` is boosted, one request at a time, by its first coupon's id.
- Delivery time picker: booked slot at the top with **Change**, or "No time booked"; day tabs with each day's price range; that day's slots with price; "Cheapest" on the lowest-priced available slot of each day; full slots show "Full". Tapping **Book** books straight away.
- Each section (Boosts, Delivery time, Order summary) has **View on Woolworths**, opening `https://www.woolworths.com.au/checkout`. Each section fails on its own; a failure whose message starts `HTTP 4` adds "Woolworths may have changed their website."
- Pick-up (`DeliveryMethod` not `"Courier"`): no slot list; "Change pick-up times on Woolworths."
- No promo codes. Substitutions, driver notes, leave unattended, pick-up slots and the address are v0.5.1, not this plan.
- Store names shown to the owner: "Woolworths". Money as `$12.00`; slot and range prices as Woolworths shows them (`$2`, `$12 - $14`, `$12.50`).
- Woolworths pages never get a JavaScript bridge. Only origin `https://appassets.androidplatform.net` may message the host. Nothing in CI talks to the real Coles or Woolworths sites.
- Commit straight to `main` with the prefix `checkout:`; the release commit is `release: v0.5.0`. CI green before the next task. There is no local Android SDK: Kotlin is compiled and tested only by CI.
- Bump the version only in Task 5. Do not touch `platra/`, the keystore, `local.properties`, `docs/seed/`, or the untracked `.superpowers/` files.

**Interfaces:**
- Produces: `window.__weekdayFuelCheckout = { start(request) -> boolean, state() -> JSON string, urls }`. `request` is `{action: "load"}` or `{action: "book", timeslotId: number, windowDate: "YYYY-MM-DD"}`; `start` returns `false` while a run is going or for any other action.
- Produces: `state()` is `{phase: "idle"|"running"|"done"|"error", result, error}`. `error` is set only when the login check fails (`"login check HTTP 503"`, or a network error message).
- Produces: `result` when logged out: `{action, loggedOut: true}`. Otherwise:
  - always: `action`, `loggedOut: false`, `method` (`"Courier"` or other), `booked` (`null` or `{id, start, end, label, cutOff}`), `minimumSpend` (number or `null`), `trolley` (stockcode numbers), `summary` (`{subtotal, savings, deliveryFee, deliveryFeeBefore, bagFee, bagLabel, total, toPay, points, warning, unavailable: [names], restricted: [names]}` or `{error}`)
  - `load` only: `boosts` (`{offers: [{id, couponId, heading, description, productId, minimumSpend, ends, outcome: "already"|"boosted"|"failed", reason}]}` or `{error}`), `windows` (`{days: [{date: "YYYY-MM-DD", available, closedText, slots: [{id, label, start, end, price, available, eco, express, cutOff}]}]}`, `{error}`, or `null` for pick-up)
  - `book` only: `bookError` (`null` when booked, else Woolworths' message or `"HTTP 500"`)

function site(over = {}) {
  return (url, init) => {
    const key = ((init && init.method) || "GET") + " " + url.split("?")[0];

async function settle(api) {
  for (let i = 0; i < 500; i++) {
    const s = JSON.parse(api.state());
    if (s.phase !== "running") return s;
    await new Promise((r) => setTimeout(r, 0));
  }
  throw new Error("checkout script did not settle");
}

/* Injected into woolworths.com.au by WoolworthsSession. Boosts every Everyday Rewards offer, reads delivery times and the order summary, and books a time, with the site's own requests. */
(function () {
  "use strict";
  if (window.__weekdayFuelCheckout) return;

  var URLS = {
    bootstrap: "/api/ui/v2/bootstrap",
    crnHash: "/api/v3/ui/shopper/rewards/crn/hash",
    offers: "https://prod.api-wr.com/wx-rtl-offer-v2/offers?filter[status]=ACTIVE",
    boost: "/api/v3/ui/rewards/offers/boost/",
    windows: "/api/v3/ui/fulfilment/windows",
    book: "/apis/ui/Fulfilment",
    summary: "/apis/ui/Checkout",
  };
  /* The site's own public client id for the offers service. */
  var CLIENT_ID = "IRfFJjr4Px9UY1XxKtSOAUYGTpelx0S0Q";
  var state = { phase: "idle", result: null, error: null };

  function message(e) {
    return String((e && e.message) || e);
  }

  async function getJson(url) {
    var r = await fetch(url, { credentials: "include", headers: { Accept: "application/json" } });
    if (!r.ok) throw new Error("HTTP " + r.status);
    return r.json();
  }

  async function section(read) {
    try {
      return await read();
    } catch (e) {
      return { error: message(e) };
    }
  }

  async function bootstrap() {
    var r = await fetch(URLS.bootstrap, { credentials: "include", headers: { Accept: "application/json" } });
    if (!r.ok) throw new Error("login check HTTP " + r.status);
    return r.json();
  }

  function delivery(boot) {
    var d = boot.GetDeliveryInfoRequest || {};
    var a = d.Address || {};
    var t = d.ReservedTime;
    return {
      method: d.DeliveryMethod || null,
      address: { addressId: a.AddressId, areaId: a.AreaId, suburbId: a.SuburbId },
      booked: t && t.Id ? { id: t.Id, start: t.StartDateTime, end: t.EndDateTime, label: t.TimeWindow, cutOff: t.CutOffDateTime || null } : null,
      minimumSpend: typeof d.MinimumSpend === "number" ? d.MinimumSpend : null,
    };
  }

  function trolleyCodes(boot) {
    var items = (boot.TrolleyRequest && boot.TrolleyRequest.AvailableItems) || [];
    return items
      .map(function (i) { return i.Stockcode; })
      .filter(function (c) { return typeof c === "number"; });
  }

  function offer(o) {
    var a = o.attributes || {};
    var d = a.display || {};
    var c = (a.coupons || [])[0] || {};
    var red = (c.attributes && c.attributes.redemption) || {};
    return {
      id: o.id,
      couponId: c.id || null,
      heading: d.heading || "",
      description: (d.description && d.description.summary) || "",
      productId: d.primaryProductId ? Number(d.primaryProductId) : null,
      minimumSpend: typeof red.minimumSpend === "number" && red.minimumSpend > 0 ? red.minimumSpend / 100 : null,
      ends: red.endDateTime || null,
      outcome: a.boostState === "BOOSTED" ? "already" : null,
      reason: null,
    };
  }

  async function boost(o) {
    if (!o.couponId) {
      o.outcome = "failed";
      o.reason = "no coupon";
      return;
    }
    try {
      var r = await fetch(URLS.boost + encodeURIComponent(o.couponId), {
        method: "POST",
        credentials: "include",
        headers: { Accept: "application/json, text/plain, */*", "Content-Type": "application/json" },
        body: "{}",
      });
      if (!r.ok) {
        o.outcome = "failed";
        o.reason = "HTTP " + r.status;
      } else if ((await r.text()).trim() === "false") {
        o.outcome = "failed";
        o.reason = "refused";
      } else {
        o.outcome = "boosted";
      }
    } catch (e) {
      o.outcome = "failed";
      o.reason = message(e);
    }
  }

  async function boostAll() {
    var hash = await getJson(URLS.crnHash);
    if (typeof hash !== "string" || !hash) throw new Error("no rewards card");
    var r = await fetch(URLS.offers, {
      headers: {
        "customer-identity": hash,
        client_id: CLIENT_ID,
        "customer-timezone": "Australia/Sydney",
        channel: "WOW_WEB",
        "Content-Type": "application/json",
      },
    });
    if (!r.ok) throw new Error("HTTP " + r.status);
    var list = await r.json();
    if (!list || !Array.isArray(list.data)) throw new Error("offers response has no list");
    var offers = list.data.map(offer);
    for (var i = 0; i < offers.length; i++) if (!offers[i].outcome) await boost(offers[i]);
    return { offers: offers };
  }

  async function windows(dlv) {
    var a = dlv.address;
    var w = await getJson(URLS.windows + "?areaId=" + a.areaId + "&fulfilmentMethod=Courier&addressId=" + a.addressId + "&suburbId=" + a.suburbId);
    if (!w || !Array.isArray(w.Days)) throw new Error("windows response has no days");
    return {
      days: w.Days.map(function (d) {
        return {
          date: String(d.Date).slice(0, 10),
          available: d.Available === true,
          closedText: d.ClosedText || "",
          slots: (d.Times || []).map(function (t) {
            return {
              id: t.Id,
              label: t.TimeWindow,
              start: t.StartDateTime,
              end: t.EndDateTime,
              price: typeof t.SalePrice === "number" ? t.SalePrice : t.Price,
              available: t.Available === true,
              eco: t.IsEcoWindow === true,
              express: t.IsExpress === true,
              cutOff: t.CutOffDateTime || null,
            };
          }),
        };
      }),
    };
  }

  async function summary() {
    var c = await getJson(URLS.summary);
    var m = c && c.Model;
    var o = m && m.Order;
    if (!o) throw new Error("summary response has no order");
    var names = function (list) {
      return (list || []).map(function (p) { return p.Name || p.Description || String(p.Stockcode); });
    };
    return {
      subtotal: o.Subtotal,
      savings: o.Savings,
      deliveryFee: o.DeliveryFee,
      deliveryFeeBefore: o.DeliveryFeeBeforeDiscount,
      bagFee: o.PackagingFee,
      bagLabel: o.PackagingFeeLabel || null,
      total: o.TotalIncludingGst,
      toPay: o.BalanceToPay,
      points: o.TotalRewardsPointsEarned,
      warning: String(m.CheckoutSubtotalErrors || ""),
      unavailable: names(o.UnavailableProducts),
      restricted: names(o.RestrictedProducts),
    };
  }

  async function book(dlv, req) {
    try {
      var r = await fetch(URLS.book, {
        method: "POST",
        credentials: "include",
        headers: { Accept: "application/json", "Content-Type": "application/json" },
        body: JSON.stringify({
          addressId: dlv.address.addressId,
          fulfilmentMethod: "Courier",
          timeslotId: req.timeslotId,
          tradingAccount: null,
          windowDate: req.windowDate,
        }),
      });
      if (!r.ok) return "HTTP " + r.status;
      var j = await r.json();
      return j && j.IsSuccessful === true ? null : (j && j.Message) || "not booked";
    } catch (e) {
      return message(e);
    }
  }

  async function run(req) {
    state = { phase: "running", result: null, error: null };
    try {
      var boot = await bootstrap();
      if (!boot || !boot.ShopperRequest || boot.ShopperRequest.IsGuest !== false) {
        state = { phase: "done", result: { action: req.action, loggedOut: true }, error: null };
        return;
      }
      var dlv = delivery(boot);
      var result = { action: req.action, loggedOut: false };
      if (req.action === "book") {
        result.bookError = await book(dlv, req);
        if (!result.bookError) {
          try {
            boot = await bootstrap();
            dlv = delivery(boot);
          } catch (e) {
            /* The booking went through; the earlier booked time is shown until the next load. */
          }
        }
      } else {
        result.boosts = await section(boostAll);
        result.windows = dlv.method === "Courier" ? await section(function () { return windows(dlv); }) : null;
      }
      result.method = dlv.method;
      result.booked = dlv.booked;
      result.minimumSpend = dlv.minimumSpend;
      result.trolley = trolleyCodes(boot);
      result.summary = await section(summary);
      state = { phase: "done", result: result, error: null };
    } catch (e) {
      state = { phase: "error", result: null, error: message(e) };
    }
  }

  window.__weekdayFuelCheckout = {
    start: function (req) {
      if (state.phase === "running") return false;
      if (!req || (req.action !== "load" && req.action !== "book")) return false;
      run(req);
      return true;
    },
    state: function () { return JSON.stringify(state); },
    urls: URLS,
  };
})();
```

package dev.weekdayfuel.app.woolworths

import org.json.JSONObject
import org.json.JSONTokener

enum class CheckoutPhase { IDLE, RUNNING, DONE, ERROR }

/** [result] is the script's result object, passed to the page as it is. */
data class CheckoutScriptState(val phase: CheckoutPhase, val result: JSONObject?, val error: String?)

object CheckoutJson {
    private val DATE = Regex("""\d{4}-\d{2}-\d{2}""")

    fun loadRequest(): String = JSONObject().put("action", "load").toString()

    /** The page's `checkoutBook` message as the script's book request, or null when the slot id or date is missing or malformed. */
    fun bookRequest(msg: JSONObject): String? {
        val id = msg.optLong("timeslotId", 0L)
        val date = msg.optString("windowDate")
        if (id <= 0L || !DATE.matches(date)) return null
        return JSONObject().put("action", "book").put("timeslotId", id).put("windowDate", date).toString()
    }

    /** [evaluateResult] is what `evaluateJavascript` returns for `__weekdayFuelCheckout.state()`: a JSON-encoded string, or "null". */
    fun parseScriptState(evaluateResult: String?): CheckoutScriptState? {
        if (evaluateResult == null || evaluateResult == "null") return null
        val raw = JSONTokener(evaluateResult).nextValue() as? String ?: return null
        val o = JSONObject(raw)
        return CheckoutScriptState(
            phase =
                when (o.optString("phase")) {
                    "running" -> CheckoutPhase.RUNNING
                    "done" -> CheckoutPhase.DONE
                    "error" -> CheckoutPhase.ERROR
                    else -> CheckoutPhase.IDLE
                },
            result = o.optJSONObject("result"),
            error = if (o.isNull("error")) null else o.optString("error"),
        )
    }
}

    private fun startCheckout() {
        val request = pendingCheckout ?: return
        if (pageLoading || !onShopPage()) return
        handler.removeCallbacks(checkoutPoller)
        checkoutPolling = true
        webView.evaluateJavascript("$checkoutScript\nwindow.__weekdayFuelCheckout.start($request);", null)
        handler.postDelayed(checkoutPoller, POLL_MS)
    }

    private fun pollCheckout() {
        if (!checkoutPolling) return
        webView.evaluateJavascript(CHECKOUT_STATE_EXPRESSION) { result ->
            if (!checkoutPolling) return@evaluateJavascript
            val state = runCatching { CheckoutJson.parseScriptState(result) }.getOrNull()
            when (state?.phase) {
                null -> {
                    // A new document dropped the script; onPageFinished or this restarts it.
                    checkoutPolling = false
                    if (!pageLoading) startCheckout()
                }
                CheckoutPhase.IDLE, CheckoutPhase.RUNNING -> handler.postDelayed(checkoutPoller, POLL_MS)
                CheckoutPhase.DONE, CheckoutPhase.ERROR -> {
                    cancelCheckout()
                    listener?.onCheckout(state)
                }
            }
        }
    }

    private fun failCheckout(message: String) {
        if (pendingCheckout == null) return
        cancelCheckout()
        listener?.onCheckout(CheckoutScriptState(CheckoutPhase.ERROR, null, message))
    }

/* Shapes the checkout script's result for the Checkout panel. Pure: no DOM, no storage. */
(function (root) {
  "use strict";

  var DAYS = ["Sun", "Mon", "Tue", "Wed", "Thu", "Fri", "Sat"];
  var MONTHS = ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"];

  function money(n) {
    return "$" + Number(n).toFixed(2);
  }

  function dollars(n) {
    return "$" + (Number(n) % 1 ? Number(n).toFixed(2) : String(Number(n)));
  }

  /* Woolworths times are store-local; only the written date and clock are used, never the device time zone. */
  function dayLabel(iso) {
    var d = new Date(Date.UTC(+iso.slice(0, 4), +iso.slice(5, 7) - 1, +iso.slice(8, 10)));
    return DAYS[d.getUTCDay()] + " " + d.getUTCDate() + " " + MONTHS[d.getUTCMonth()];
  }

  function timeLabel(iso) {
    var h = +iso.slice(11, 13);
    var m = iso.slice(14, 16);
    return (h % 12 || 12) + (m === "00" ? "" : ":" + m) + (h < 12 ? "am" : "pm");
  }

  function bookedLabel(b) {
    return {
      when: dayLabel(b.start) + ", " + b.label,
      cutOff: b.cutOff ? "Change by " + dayLabel(b.cutOff) + " " + timeLabel(b.cutOff) : null,
    };
  }

  function boostSummary(boosts, trolley) {
    var codes = {};
    (trolley || []).forEach(function (c) {
      codes[c] = true;
    });
    var rows = ((boosts && boosts.offers) || []).map(function (o, i) {
      return {
        heading: o.heading,
        description: o.description,
        minSpend: o.minimumSpend ? dollars(o.minimumSpend) : null,
        inTrolley: o.productId != null && codes[o.productId] === true,
        outcome: o.outcome,
        reason: o.reason || null,
        order: i,
      };
    });
    rows.sort(function (a, b) {
      return (a.inTrolley ? 0 : 1) - (b.inTrolley ? 0 : 1) || a.order - b.order;
    });
    function count(outcome) {
      return rows.filter(function (r) { return r.outcome === outcome; }).length;
    }
    return {
      boosted: count("boosted"),
      already: count("already"),
      rows: rows.filter(function (r) { return r.outcome !== "failed"; }),
      failed: rows.filter(function (r) { return r.outcome === "failed"; }),
    };
  }

  function dayTabs(windows) {
    return ((windows && windows.days) || []).map(function (d) {
      var open = d.available
        ? d.slots.filter(function (s) { return s.available && typeof s.price === "number"; })
        : [];
      var prices = open.map(function (s) { return s.price; });
      var min = prices.length ? Math.min.apply(null, prices) : null;
      var max = prices.length ? Math.max.apply(null, prices) : null;
      var cheapest = open.filter(function (s) { return s.price === min; })[0];
      return {
        date: d.date,
        open: open.length > 0,
        priceRange: min == null ? null : min === max ? dollars(min) : dollars(min) + " - " + dollars(max),
        cheapestId: cheapest ? cheapest.id : null,
        closedText: d.closedText || "",
        slots: d.slots,
      };
    });
  }

  function summaryLines(s) {
    var lines = [
      { label: "Subtotal", value: money(s.subtotal), note: s.savings > 0 ? "you've saved " + money(s.savings) : null, strong: false },
      { label: "Delivery fee", value: money(s.deliveryFee), note: s.deliveryFeeBefore > s.deliveryFee ? "was " + money(s.deliveryFeeBefore) : null, strong: false },
    ];
    if (s.bagFee > 0) lines.push({ label: s.bagLabel || "Bag fee", value: money(s.bagFee), note: null, strong: false });
    lines.push({ label: "Total", value: money(s.total), note: null, strong: true });
    return lines;
  }

  var api = {
    money: money,
    dollars: dollars,
    dayLabel: dayLabel,
    timeLabel: timeLabel,
    bookedLabel: bookedLabel,
    boostSummary: boostSummary,
    dayTabs: dayTabs,
    summaryLines: summaryLines,
  };
  if (typeof module === "object" && module.exports) module.exports = api;
  else root.WeekdayFuelCheckoutView = api;
})(this);
```
